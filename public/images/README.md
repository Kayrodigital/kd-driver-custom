# Images d'ambiance — /design-preview

Dépose les fichiers ci-dessous dans ce dossier (`public/images/`) avec
exactement ces noms. Ils sont déjà branchés dans la maquette : dès qu'un
fichier existe, il remplace automatiquement le dégradé de secours.

| Fichier | Utilisation | Format conseillé |
|---|---|---|
| `hero-lyon.jpg` | Fond du hero (variantes A et B) | paysage, 2400×1400 mini, sombre ou assombrissable |
| `vehicle-berline.jpg` | Carte véhicule « Berline » | paysage 16:10, ~1200×750 |
| `vehicle-confort.jpg` | Carte véhicule « Confort » | paysage 16:10, ~1200×750 |
| `vehicle-van.jpg` | Carte véhicule « Van » | paysage 16:10, ~1200×750 |
| `airport-transfer.jpg` | Section « Aéroport & gares » | paysage, ~1600×1000 |
| `corporate.jpg` | Section « Entreprise » | paysage, ~1600×1000 |

Le hero applique automatiquement un assombrissement (dégradé + `brightness`)
pour garder le texte lisible — pas besoin de préassombrir la photo toi-même.
